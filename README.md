# Handframe website

A single-page website for Handframe, an AI video studio in Dehradun.
It is one file (`index.html`), so there is nothing to install or build.

## Put it live with GitHub Pages (free, no coding)

1. Create a free account at https://github.com if you don't have one.
2. Click **+** (top right) > **New repository**.
   - Name it `handframe` (or `YOURUSERNAME.github.io` to get a shorter address).
   - Choose **Public** (free GitHub Pages needs a public repository).
   - Click **Create repository**.
3. On the new repository page, click **uploading an existing file**.
4. Unzip this folder, then drag `index.html` and `robots.txt` into the upload box
   (add `README.md` too if you like). Click **Commit changes**.
5. Open **Settings > Pages**.
   - Under **Build and deployment**, set **Source** to **Deploy from a branch**.
   - Set **Branch** to `main` and the folder to `/ (root)`, then click **Save**.
6. Wait 1 to 2 minutes and refresh. GitHub shows your live address at the top of the Pages screen:
   - `https://YOURUSERNAME.github.io/handframe/` (repository called `handframe`)
   - `https://YOURUSERNAME.github.io/` (repository called `YOURUSERNAME.github.io`)

## Before you share the link, replace the placeholders

Open `index.html` on GitHub, click the pencil icon (Edit), press Ctrl+F (Cmd+F on Mac) and search for:

| Search for | Replace with |
|---|---|
| `91XXXXXXXXXX` | your WhatsApp number with country code, no + or spaces (for example `919876543210`). It appears in 2 places. |
| `your@email.com` | your business email |
| `@yourhandle` | your Instagram handle |
| `Replace this with a real client quote` | real client quotes (once you have clients) |
| `Team member` and the role lines | your real team names and roles |

Then click **Commit changes**. The live site updates in about a minute.

## Good to know

- The page loads two handwriting fonts from Google Fonts, so visitors need an internet connection to see them.
- Sound is off by default. Visitors can switch it on with the button in the corner.
- To use your own domain later: **Settings > Pages > Custom domain**, then add the DNS records your domain provider asks for.
- Work videos and the photos-to-film images are still placeholders. Add them as you finish projects.
